# nextleet

Fetches your LeetCode profile data (solved problems, submission history, skill gaps) and suggests which problem you should do next — so you don't have to figure out what you're weak at on your own.

Tech stack and implementation undecided. This repo just holds the idea for now.

## Directions (undecided)

Leaning **Go**, since I always reach for web apps and want something different.

- **CLI** — Go `cobra` or Rust `clap`
- **Desktop GUI** — Rust `egui` / Tauri
